# Team Module Contributions

This folder is for individual team member contribution files.

Please create your own file here and commit it from your own GitHub account.

Do not edit the real Flutter app folders directly.

## Required files

- `adil_dashboard_navigation_code.md`
- `newal_assignment_module_code.md`
- `marwa_group_project_module_code.md`
- `abubakar_file_reminder_module_code.md`

Each file should include the member name, assigned module, explanation, and suggested Dart code for their module.
